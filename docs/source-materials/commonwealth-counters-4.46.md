# Commonwealth counters — §4.46 type symbols (PDF p.184–185)

Ground-truth transcription of the §4.46 unit-type glyphs on the Commonwealth counter sheets,
read from the vector PDF rendered at 400 DPI (`tools/pdf-page.sh … 184` and `… 185`). Built to
verify the §20.3 Replacement-Point conversion classifier (D14). Flagged special types
(MG / anti-tank / anti-air / recce / motorized / artillery) are what the classifier must resolve.

## Orientation / scope
- **p.184** renders right-side-up (no rotation); **p.185** renders upside-down (rotate 180°).
- **p.184** red "COMMONWEALTH" area = step-markers, SGSU supply, air (BOMBER/FIGHTER/TRANSPORT),
  naval (DD/CL/CA/BB), repair, INF/GUN replacement, and generic tank silhouettes A–E → excluded
  (not §4.46 ground combat units). Combat units on p.184 = the orange block: **New Zealand + Free
  French / Greek / Polish / Czech** contingents.
- **p.185** = Counter Sections Nr. 7 & 8 = the main **British / Indian / South African / Australian**
  block (genuine continuation, included).
- **p.186** = Counter Section Nr. 9 = game markers → excluded.

## Glyph legend (confirmed on these sheets)
X = Infantry · centre DOT = Artillery (Fd/RHA/Med) · upward TRIANGLE **no** dot = Anti-Aircraft
(LAA/HAA) · TRIANGLE **+** dot = Anti-tank · X **+** central star/burst = MG · horizontal OVAL =
Armor (RTR/tank) · OVAL+diagonal-slash / oval-on-bogies = Recce/Armored-car/Cavalry · X+wheels =
Motorized/lorried infantry · "RR"-in-box = rail unit. Size: XX=div, X=bde, III=regt, II=battalion,
I=coy/battery. Qty "(N)" (absent ⇒ 1).

## Caveats / uncertainties
- **102(NH)** — glyph read as A/T by one pass, AA by another. Historically 102nd (Northumberland
  Hussars) = Anti-Tank Regt → listed Anti-tank; flagged for re-zoom.
- **2/1AusP** (Aus Pioneer) — Engineer/Pioneer vs MG ambiguous.
- **1FMtMr** (Free French) — wheels+X+dot; motorized/wheeled, exact role unclear.
- **10NZ / 13NZ** — "RR"-in-box (rail unit), strength 0.
- A few unattached British designations (RYugGd, Selby, "A"/SpServ) and some parent tags near band
  edges are less certain; **types are high-confidence throughout**.
- **14 (14/70 A/T Coy) and 65 (65th A/T Regt)** — both counters are drawn with the **plain artillery
  dot**, not the AT chevron+dot. This is a **counter-art anomaly**: their §4.44a OA-sheet id codes
  ("dd" and "aa" respectively) and 2-pounder A/T armament are authoritative, so the OB models both as
  **AntiTank** (resolved 2026-09-16, p185 CW verification pass). Contrast their siblings 16 & 23 A/T
  coys and the 73rd A/T Regt, which *are* drawn with the AT chevron+dot. Do not re-flag.
