# The Air Game (§33–48) — build plan

Large system, built incrementally. Structure: §33 sequence, §34 aircraft, §35 SGSU, §36 air
facilities, §37 flight, §38 readying, §39 missions, §40 fighter combat, §41 bombing, §42 transfer,
§43 Axis/Med, §44 Malta, §45 air-to-air, §46 AA/flak, §47 abstract logistics, §48 sequence.

## Build order
1. **Aircraft reference data (§34)** — plane roster + ratings. *(In progress.)*
2. Squadrons + SGSU (§35) + air facilities/airfields (§36).
3. Flight, range, readying (§37–38).
4. Missions + fighter/air-to-air combat + AA (§39–41, §45–46).
5. Malta, Axis/Med, abstract logistics (§43–44, §47).
