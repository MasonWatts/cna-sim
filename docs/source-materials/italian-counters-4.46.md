# Italian Combat-Unit Counters — §4.46 Symbol Ground Truth

**Source:** *The Campaign for North Africa* (SPI, 1978), PDF page 182 — "Counter Section Nr. 1 & 2" (Italian counters), rendered at 400 DPI (upright, ~4400×6800 px).

**Method:** Page rendered with `tools/pdf-page.sh`, cropped into full-width per-group horizontal strips (left column-group x≈80–2085, right column-group x≈2105–4360), upscaled ~2–4× (PIL LANCZOS), read visually. Ambiguous glyphs were re-cropped at 3–4× for confirmation. Each sheet is a 10-row × 10-column grid per group (200 pieces/sheet, 400 total).

**Counter layout:** top-left `(N)` = quantity of identical counters (absent = 1); top-center = combat value; top-right = size (XX=division, X=brigade, III=regiment, II=battalion, I=company); center box = §4.46 type glyph; below box = designation; bottom = parent formation (`-` or `*` = independent). Top-left letters `G`/`EG`/`E` are class/nationality markers (G ≈ Garrison), recorded in Notes.

## Symbol legend used (center glyph → type)

| Glyph | Type |
|---|---|
| X in box | Infantry |
| X in box + vertical bar through top | Heavy-weapons / mortar **(uncertain — see notes)** |
| X in box + two wheels beneath | Motorized infantry |
| X in box + star | Infantry (special/Blackshirt marking) |
| horizontal oval | Armor / Tank (L=light, M=medium per designation) |
| oval on small bogies/wheels | Armored car / motorized recon |
| box + single diagonal slash | Cavalry (with `c` = camel / Meharisti) |
| box + diagonal slash + wheels | Motorized reconnaissance (motorcycle recce) |
| box + filled dot | Artillery (+ parachute arc = parachute artillery) |
| box + three vertical bars | Machine-gun |
| box + oval-with-dot ("eye") | Coastal-defense / fortress gun |
| box + triangle (trapezoid) | AA / position defense **(unclassified — not in §4.46 crib)** |
| box + triangle + dot | AA / anti-tank support **(unclassified)** |
| text-only `SGSU nn / 20` | Supply unit (non-combat — excluded below) |

**Notes on uncertainty:**
- **X-box + vertical bar** ("Heavy weapons"): a distinct infantry-derived glyph appearing once per infantry division (numbered = division), plus the Sahara group and the Marines. Best interpretation is a mortar/heavy-weapons battalion; flagged `?`.
- **Triangle** and **triangle+dot** glyphs are not defined in the supplied crib; classified as AA/position/AT support, flagged `?`. Frequently attached to garrison/coastal (CD) formations.
- **31Guast** ("Guastatori" = assault engineers) carries the three-bar (MG) glyph; recorded as MG-glyph with an engineer-designation caveat.
- 19 `SGSU` supply counters (Sheet 2 right, rows 8–10) are non-combat and are omitted from the table (listed at end).
